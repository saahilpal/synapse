# Architecture Decision Records

ADRs capture durable technical decisions for Synapse. Use them when a choice affects storage, runtime semantics, security, interfaces, or long-term extensibility.

## ADR Format

- Status
- Context
- Decision
- Consequences
- Alternatives Considered
