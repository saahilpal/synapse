# Getting Support for Synapse

We want to make your experience with Synapse as smooth and productive as possible. Please consult the resources below if you run into problems, have questions, or want to suggest improvements.

## 1. Documentation
Before opening an issue or seeking manual support, check our structured documentation:
- **Beginner Onboarding & Quickstart**: [README.md](README.md)
- **Subsystem Architecture Deep Dive**: Read the Markdown files in [docs/architecture/](docs/architecture/)
- **Visual Diagram Guides**: Read the workflow visualizers in [docs/diagrams/](docs/diagrams/)
- **Local Dev & Troubleshooting**: Read [docs/troubleshooting.md](docs/troubleshooting.md)

## 2. GitHub Issues
If you encounter bugs, regressions, or have feature suggestions, please check existing issues or open a new one:
- **Bug Reports**: Use the bug template to describe your environment (OS, Python version, IDE settings), reproduction steps, and the expected vs. actual outcomes.
- **Feature Requests**: Describe the problem you want to solve and your proposed interface/behavior.

*Please note: For security-sensitive vulnerability disclosures, refer to the private coordination process in our [SECURITY.md](SECURITY.md) policy instead of creating a public issue.*

## 3. Discussion Forums & Community
For questions about configuring custom agents, using the MCP tool interfaces, or general conceptual discussions:
- **GitHub Discussions**: Post questions, share your custom agent setups, and collaborate with the community on advanced temporal graphs.

## 4. Professional Support & Custom Integrations
For enterprise support, private onboarding workshops, or custom graph projection integrations, please contact the project maintainers directly via the maintainer coordinates listed in the repository organization description.
